# A Matemática numa Propriedade Agrícola (3D)

**Um único ficheiro:** `index.html` já tem dentro os estilos, o código, a foto aérea e as figuras. Não há pastas nem caminhos que possam falhar.

## Pôr no ar (GitHub Pages)
1. No repositório (público), apaga os ficheiros antigos. Em "Add file → Upload files", envia o `index.html`. Commit changes.
2. Settings → Pages → Source: "Deploy from a branch" → `main` → `/ (root)` → Save.
3. Espera 1 a 2 minutos: https://brunklj01.github.io/Matematica/

O computador precisa de internet (o Three.js é carregado da internet).

## Controlos
← → cenas · espaço reproduz/pausa · G grelha · V vista aérea · R repor vista · F ecrã inteiro · M modo apresentação. "Modo slides": cada cena fica parada. Rato: arrastar roda, scroll aproxima, botão direito desloca.

## Ordem das cenas
1 Referencial cartesiano · 2 Coordenadas dos pontos · 3 Reta horizontal · 4 Reta vertical · 5 Reta diagonal · 6 Semiplano y > 0 · 7 Semiplano x > 0 · 8 Semiplano y < x − 4 · 9 Conjunção x > 0 E y > 0 · 10 Disjunção · 11 Conjunção das três condições · 12 Resumo das três retas.

## Modelo do Blender (opcional)
Coloca `propriedade.glb` ao lado do `index.html` (origem no cruzamento das estradas, 100 m = 2 unidades). Funciona quando o site está online.
